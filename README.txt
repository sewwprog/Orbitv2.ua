Orbit — локальна дошка для телефону, ПК та PWA

Запуск
1. Відкрийте index.html у браузері. Для звичайної роботи збирання та сторонні бібліотеки не потрібні.
2. Для встановлення PWA розмістіть файли репозиторію разом на HTTPS-сайті та виберіть у браузері встановлення або додавання на головний екран.
3. Один раз відкрийте сайт з інтернетом, щоб підготувати офлайн-запуск.

Інтерфейс
- Панелі враховують безпечні зони екрана; на вузькому телефоні інструменти розташовані у два ряди.
- Масштаб дошки змінюється кнопками або жестом двома пальцями.
- Вміст довгих меню прокручується окремо, кнопка закриття залишається доступною.
- Скляні панелі мають непрозорий варіант для системного режиму зменшення прозорості.

Дошки зберігаються локально для адреси сайту. Для перенесення з локального HTML чи іншої адреси скористайтеся експортом/імпортом JSON.

Автоматичні перевірки описані в README.md. Розміри екрана, безпечні зони та клавіатура перевірялися емуляцією Chromium; фізичні телефони не тестувалися.
