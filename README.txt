Orbit / LipnotGram — версія для телефона та PWA

Що змінено
- Відступи під виріз екрана й нижню системну панель.
- Нижня панель інструментів у портретному та горизонтальному режимах.
- Меню та поля підлаштовуються під видиму область із клавіатурою.
- Виправлено переповнення меню на вузьких екранах.
- Додано manifest, іконки та service worker для встановлення й офлайн-запуску.

Запуск
1. index.html можна відкрити локально, як раніше.
2. Для встановлення PWA завантажте весь вміст цієї папки на HTTPS-сайт, зберігши структуру icons/.
3. Відкрийте сайт на телефоні й виберіть встановлення / додавання на головний екран у меню браузера.
4. Один раз відкрийте сайт з інтернетом, щоб підготувати офлайн-запуск.

Перевірено в браузері з емуляцією: 320×568, 390×844, 844×390, 1440×900; створення дошки, редагування, збереження після перезапуску, офлайн та локальний HTML. Виріз екрана й клавіатуру перевірено симуляцією; фізичний iPhone/Android не тестувався.

Логіка збереження, структура даних, зв’язки та історія не змінені. У початковому скрипті змінено лише розрахунок видимості курсора відносно шапки. Оригінал збережено поруч із вихідним index.html як index.before-pwa.html.
Дошки зберігаються локально для адреси сайту. Для перенесення з локального HTML чи іншої адреси скористайтеся наявним експортом/імпортом JSON.

Вимоги до встановлення PWA: https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable
