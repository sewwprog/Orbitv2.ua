# Orbit

Локальна дошка для нотаток, задач, зв’язків і графіків. Відкрийте `index.html` у браузері або розмістіть файли репозиторію на HTTPS-сайті. Збірка та сторонні бібліотеки для графіків не потрібні.

## Графіки

1. Відкрийте дошку та натисніть кнопку **Графік** на панелі інструментів. Вона також є в меню **Ще → Створити графік**.
2. Вкажіть назву графіка й назви осей X та Y. Виберіть дати або числову вісь X.
3. Додайте дату, значення Y та необов’язковий текст підказки. У числовому режимі також введіть X.
4. Натисніть **Додати точку**. Наступна дата підставиться автоматично; її можна змінити.
5. У таблиці можна редагувати й видаляти точки. Дати та координати X впорядковуються автоматично. Повторні дати (у режимі дат) або X (у числовому режимі) не допускаються.

Значення задаються окремо для кожної точки: **100 → 22 → 130** створює спад і зростання. Це не накопичувальна сума. Підтримуються нуль, від’ємні та дробові значення, зокрема з десятковою комою.

На ПК наведіть курсор на точку, на телефоні торкніться її — з’являться значення й текст. Подвійне натискання або Enter на точці відкриває її редагування. Подвійне натискання на блок відкриває редактор графіка.

Налаштування: лінія, заливка чи стовпчики; колір; числа біля точок; шкала Y від нуля; період від/до дати. Кнопки стрілок на блоці переміщують видимий період на 7 днів; **Усі дні** повертає повний графік. Кут блока змінює його розмір.

Графіки підтримують скасування/повторення, дублювання, зв’язки з іншими блоками, експорт/імпорт JSON, PNG дошки та CSV таблиці. Максимум — 2000 точок у графіку.

## Збереження та офлайн

Дошки зберігаються в IndexedDB цього браузера на цьому пристрої. Для перенесення на інший пристрій або іншу адресу використовуйте JSON. Графіки працюють без інтернету; service worker кешує HTML, manifest та іконки для офлайн-запуску встановленого застосунку.

## Перевірки

Зміни перевірено в Chromium: зростання/спад, підказки, зміна дат, дробові/від’ємні/нульові значення, заборона дублікатів, числова вісь X, стилі, CSV, JSON з повторним імпортом, PNG, збереження після перезавантаження, скасування/повторення, дублювання, видалення точок, офлайн-запуск та екрани 1440×900, 390×844 і 320×568. Фізичні телефони не тестувалися.
